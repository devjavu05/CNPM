# frontEnd

This frontend is now a React + Vite application organized into dedicated modules.

Run:

1. Start the Spring Boot backend at `http://localhost:8080`
2. Install dependencies in `frontEnd`
3. Start the React dev server

Commands:

```bash
npm install
npm run dev
```

Main routes:

- `/` home
- `/login` sign in
- `/register` reader registration
- `/dashboard` workspace hub
- `/catalog` catalog and inventory
- `/reservations` reservations module
- `/circulation` loans, details, and fines
- `/staff` staffing module
- `/admin` administration module
